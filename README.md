# Lista de Exercícios - Curso FullStack +PraTi

Este repositório contém uma lista de exercícios em JavaScript desenvolvidos durante o curso FullStack da +PraTi. Os exercícios utilizam o ambiente Node.js e a biblioteca `prompt-sync` para entrada de dados do usuário via terminal.

## ✅ Requisitos

Antes de executar os exercícios, você precisa ter o seguinte programa instalado na sua máquina:

- [Node.js](https://nodejs.org/) (versão LTS recomendada)
- biblioteca prompt-sync
- Git (opcional, mas recomendado para clonar o repositório)
- Editor de texto como o Visual Studio Code.

## 📦 Como clonar e executar


1 - Abra o terminal de sua preferencia. Eu estou usando o Command Prompt.

2 - Garanta que você esteja na pasta correta onde quer clonar o repositório.

3 - Digite o comando: git clone https://github.com/SeuUsuario/NomeDoRepositorio.git e der Enter.

📚 Tecnologias usadas :
- JavaScript (Node.js)
- Biblioteca prompt-sync

## Para instalar a Biblioteca Prompt-sync:
- No terminal digitar npm install prompt-sync
## Para instalar o Node.js:
. Acesse o site oficial: https://nodejs.org/  
. Baixe e instale a versão LTS para seu sistema operacional.
